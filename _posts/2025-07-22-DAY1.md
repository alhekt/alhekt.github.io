# 01. 프론트엔드 - 로그인 페이지 스켈레톤 만들기

우선 HTML과 PHP를 사용해 **입력폼(아이디/비밀번호)**을 구성합니다.  
여기서는 **DB 없이 단순한 로그인 구조의 뼈대(Skeleton)**를 만드는 것이 목표입니다.
```php
<html>
<head>
        <meta charset="utf-8">
        <title>로그인 페이지</title>
</head>
<body>
<form method="POST" action="index_login.php"/>
        <input type="text" name="username" placeholder="아이디"/>
        <input type="password" name="userpassword" placeholder="비밀번호"/>
        <input type="submit" value="로그인">
</form>
</body>
</html>
```


# 02. 백엔드 - 로그인 처리 로직 구현

DB 없이 로그인 기능을 처리하기 위해 조건문 (if / else) 와 변수만으로 인증을 구현합니다.
이 파일은 사용자가 입력한 값이 **관리자 계정(admin / admin1234)**과 일치하는지 확인합니다.
```php
<?php
        $id = $_POST["username"];
        $pass = $_POST["userpassword"];

        if($id == admin && $pass == admin1234){
                echo "로그인이 성공하였습니다.";
        }else{
                echo "로그인에 실패하였습니다.";
        }
?>
```
