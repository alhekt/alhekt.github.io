# 01. 먼저 로그인 페이지를 만들기 위해 프론트엔드를 사용하여 **스켈레톤(Skeleton)** 코드를 작성합니다.
# #index.php (**프론트엔드 - 로그인 페이지 뼈대**)
```php
<html>
<head>
        <meta charset="utf-8">
        <title>로그인 페이지</title>
</head>
<body>
<form method="POST" action="index_login.php"/>
        <input type="text" name="username" placeholder="아이디"/>
        <input type="password" name="userpassword" placeholder="비밀번호"/>
        <input type="submit" value="로그인">
</form>
</body>
</html>
```

# 02. DB를 사용하지 않고 로그인 페이지를 구현하는 시나리오 였으므로 변수, if문, and(&&), else문 등을 사용하여 아이디와 패스워드가 일치하는지 확인해주는 기능을 하는 백엔드 페이지를 만들어줍니다.
# #index_login-process.php (**백엔드 - 로그인을 가능하게 해주는 기능 역할 페이지**)
```php
<?php
        $id = $_POST["username"];
        $pass = $_POST["userpassword"];

        if($id == admin && $pass == admin1234){
                echo "로그인이 성공하였습니다.";
        }else{
                echo "로그인에 실패하였습니다.";
        }
?>
```
